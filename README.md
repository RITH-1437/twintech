# TwinTech

A modern full-stack computer inventory, repair, and asset management platform built with Laravel, Vue.js, PostgreSQL, and Docker.

## Features

- Computer Asset Management
- Hardware Inventory
- Repair & Maintenance
- Asset Assignment
- Role-Based Access Control
- Analytics Dashboard
- Activity Logs
- RESTful API
- Dockerized Development

## Tech Stack

- Laravel 12
- Vue 3
- TypeScript
- Tailwind CSS
- PostgreSQL
- Docker
- Redis
